Repository README

Project overview

Orion is a full-stack ASP.NET Core web application (Razor Pages) with PostgreSQL and ASP.NET Identity. It combines an e-commerce storefront, artisan profiles, donation flows and admin dashboards. This page is a GitHub Pages-friendly project landing page for your portfolio.

To preview the live app, deploy the backend (Azure, Railway, Render or similar) — this static page is for the portfolio and docs.

Highlights

  • Product catalog with search and categories
  • Freelancer / artisan profiles with photos
  • Shopping cart and checkout flow
  • Admin & supervisor dashboards
  • SendGrid email notifications and JWT authentication

Run locally

  1. Clone the repo: git clone https://github.com/AmrMa3owad/Orion.git
  2. See appsettings.example.json in the repo and configure your PostgreSQL connection string.
  3. Run migrations and start: dotnet ef database update --project Orion.Context --startup-project Orion then dotnet run --project Orion

Enable GitHub Pages

  1. Go to your repository on GitHub: Settings > Pages.
  2. Under "Source" choose the branch (master) and the /docs folder, then Save.
  3. The site will be available at https://AmrMa3owad.github.io/Orion/ (it may take a minute to publish).
